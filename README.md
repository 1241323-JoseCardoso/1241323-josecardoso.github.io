# Portefólio — José Cardoso

Site pessoal para publicar gratuitamente em GitHub Pages.

## Publicar

1. Cria um repositório **público** chamado exatamente `1241323-josecardoso.github.io`.
2. Carrega o ficheiro `index.html` para a raiz do repositório (`Add file` > `Upload files`) e confirma em `Commit changes`.
3. Entra em `Settings` > `Pages`.
4. Em `Build and deployment` > `Source`, escolhe `Deploy from a branch`.
5. Escolhe o branch `main`, a pasta `/ (root)` e clica em `Save`.
6. Abre https://1241323-josecardoso.github.io/ quando o GitHub terminar a publicação.

Nota: usa o nome do repositório **todo em minúsculas**, mesmo que o teu username contenha letras maiúsculas.

## Personalizar

O site usa um único ficheiro (`index.html`). Podes editar diretamente no GitHub, clicando no ficheiro e no ícone do lápis.

- Altera os textos de apresentação na secção com `id="inicio"`.
- Altera a biografia na secção com `id="sobre"`.
- Substitui os dois cartões "Em breve" pelos teus projetos, com títulos, descrições e links reais.
- Edita as cores no início do CSS, nas variáveis `--bg`, `--surface` e `--accent`.

Não precisas de instalar nada nem de configurar um servidor.
